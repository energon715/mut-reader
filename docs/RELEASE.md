# Состояние выпуска: 1.0.0-rc.1

Ветка `docs/v1.0.0-plan`, 13 октября 2026. Это устанавливаемый кандидат,
а не объявление публичной 1.0.0. План: [V1_0_0_CHECKLIST.md](V1_0_0_CHECKLIST.md).

## Реализовано и проверено здесь

- Настоящие PDF/EPUB/FB2, навигация, выделение текста PDF, локальные ресурсы,
  зашифрованные позиции и закладки. Исправлен цикл реактивной отрисовки canvas.
- Полки, поиск/фильтры, обложки, детали книги, пакетный импорт и импорт папки,
  отдельные редакции дубликатов, остановка импорта, экспорт и удаление из каталога.
- Стандартные папки, native-диалоги, сохранение выбранных путей, последние
  6 символов при подтверждении recovery; полный код для доступа.
- Копии и восстановление с проверкой манифеста, AEAD оригиналов/обложек,
  SHA-256 оригиналов; CLI с теми же проверками и скрытым вводом секрета.
- Валидация KDF, nonce, UUID и путей; ограничения XML, ZIP и изображений;
  атомарные записи с fsync, отклонение перезаписи, mutex и desktop flock.
- Автоблокировка, закрытие сессии при завершении окна; код и метаданные
  убираются из UI при блокировке. Настройки хранят только оформление и пути.
- MPL-2.0, лицензии зависимостей, спецификация формата, инструкции,
  workflow CI и скрипты сборки deb/tar.gz с SHA256SUMS.

## Сборка и установка

Команды сборки — в [README](../README.md). `scripts/collect-licenses.py`
собирает лицензии реально используемых Linux Go-модулей и frontend runtime.
`package-linux.py` проверяет `ldd`, кладёт оба бинарника, desktop entry, иконку,
лицензии, версии зависимостей и инструкции в deb и tar.gz.

Проверьте `sha256sum -c SHA256SUMS` в папке `dist`. Контрольные суммы не являются
подписью издателя. Для deb на Debian/Ubuntu: `sudo apt install ./mut-1.0.0-rc.1-amd64.deb`.
Для ручной установки распакуйте tar.gz в отдельную папку и запустите `usr/bin/mut`;
на хосте нужны GTK 3 и WebKitGTK 4.1. Не распаковывайте пакет поверх рабочего сейфа.
Установка через apt на этой Arch-машине не проверялась.

## Как повторить нативную проверку

```sh
python3 scripts/reader-fixtures.py /tmp/mut-native-e2e
wails build -tags webkit2_41 -skipbindings -devtools -o mut-inspect
WEBKIT_INSPECTOR_HTTP_SERVER=127.0.0.1:9223 \
MUT_VAULT_PATH=/tmp/mut-native-e2e/default \
XDG_CACHE_HOME=/tmp/mut-native-cache XDG_DATA_HOME=/tmp/mut-native-data \
GDK_BACKEND=x11 ./build/bin/mut-inspect
# В другом терминале:
node scripts/native-smoke.mjs /tmp/mut-native-e2e
node scripts/native-restart.mjs prepare /tmp/mut-native-e2e
# Закройте и запустите тот же изолированный процесс с теми же переменными.
node scripts/native-restart.mjs verify /tmp/mut-native-e2e
```

Тесты используют собственный текст и PDF из фикстур, никаких скачанных книг.
Remote inspector предназначен только для локального теста, не включайте его
в повседневной работе с личной библиотекой. Production binary собран без devtools.

## До публичной 1.0.0

- Независимое ревью криптографии, формата, недоверенного контента и замечаний
  о сохранности; пока формат не объявлен замороженным.
- Испытания аварий питания, ENOSPC/ошибок fsync и аварий на каждом этапе
  полного импорта, создания и смены пароля. При ошибке после rename состояние
  на диске может быть уже новым; каталог перечитывается, ошибка остаётся видимой.
- Восстановление на чистой машине без сети, установка deb, Ubuntu/Fedora,
  HiDPI и слабый ноутбук, реальные большие/многоязычные/повреждённые книги.
- Нагрузочный прогон реальных коллекций, бюджеты запуска/импорта/чтения,
  проверка сетевого трафика всей ОС и постоянных кешей WebKit.
- Пользовательское испытание друзьями, видео полного цикла и публикация
  проверенного артефакта с тегом `v1.0.0` после закрытия критериев.

Сейчас лимит импорта 256 МиБ, чтения 64 МиБ. EPUB/FB2 показывают ограниченный
текст/растровые изображения. PDF с паролем не поддерживается. Удаление книги
не очищает старые snapshots/объекты. Backup сохраняет весь разрешённый архив,
включая историю. Блокировка памяти не является гарантией secure erasure.

## Проверка исправлений читалки — 14 октября 2026

`native-smoke.mjs` повторно прошёл полный цикл UI с тремя форматами.
`native-reader-regression.mjs` проверил длинный EPUB (5 частей), покрытие
фоном до конца текста/PDF, PDF с увеличенным масштабом, видимость нижней
навигации после прокрутки, сброс прокрутки при переходе, добавление/открытие/
удаление закладки с проверкой каталога и пустой ввод номера страницы.

Для повторения после `native-smoke.mjs`:
`node scripts/native-reader-regression.mjs /tmp/mut-native-e2e`.
Длинную фикстуру создаёт общий `reader-fixtures.py`.
Исправления не меняют Go-ядро или формат архива.

## Настройки и безопасность — 14 октября 2026

Системные select в настройках/сортировке заменены собственными меню с
описаниями, отметкой текущего выбора, клавиатурой и анимацией. Закрытие настроек
анимируется 180 мс; блокировка уничтожает окно немедленно. Учитывается reduced motion.
`native-settings-regression.mjs` проверяет границы меню, выбор/сохранение,
Escape, анимацию, блокировку и отключение password autofill.

Исправлены ограничения повторяющихся элементов книги, FB2 binary и открытие
FIFO. Результаты и остающийся риск WebKit — в
[проверке безопасности](SECURITY_REVIEW_2026-10-14.md). Сборка деб-пакета теперь
требует WebKitGTK >= 2.54.0; версия 2.52.6 остаётся только фактической средой
выполненных проверок и не удовлетворяет новому требованию безопасности.

## Linux x86-64 поставка — 14 октября 2026

Подготовлены AppImage, DEB и tar.gz в Debian 13 с Go 1.27.2/Node 24.21.0.
AppImage содержит WebKitGTK `2.54.0-1~deb13u2` и требует glibc >= 2.39;
DEB имеет зависимости `dpkg-shlibdeps` и минимум WebKitGTK 2.54.0.
[Пакеты, установка, публикация и границы проверки](LINUX_PACKAGES.md).

Runtime прошёл полный цикл UI в Arch и изолированной Ubuntu 24.04. Проверены
отдельные пространства имён и seccomp процесса страницы; sandbox явно включён
в desktop entry point. Проверка готового AppImage сравнивает ELF/build IDs
с production-сборкой и проверяет CLI, процессы WebKit, launcher и лицензии.
GitHub workflow собирает пакеты и сохраняет Actions artifact; публикация
Release не выполняется автоматически. Соответствующие исходники runtime
поставляются отдельно. Версия остаётся `1.0.0-rc.1`.
