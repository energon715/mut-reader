# Проверка безопасности — 14 октября 2026

Ветка `docs/v1.0.0-plan`. Это проверка зависимостей и целевой разбор кода,
а не независимый аудит криптографии или гарантия отсутствия уязвимостей.
Рабочая библиотека не использовалась: тесты выполнялись на собственных
фикстурах в `/tmp`.

## Результаты зависимостей

| Проверка | Результат |

| `npm audit --json` | 0 известных уязвимостей, включая dev-зависимости |

Общее сообщение для неиспользуемого openpgp не означает, что эти алгоритмы
помечены этим же бюллетенем как уязвимые.

## Исправленные проблемы

### Разрастание модели книги — отказ в обслуживании

Лимиты ZIP и размера входного файла не ограничивали повторяющиеся элементы
в результирующем документе. EPUB мог ссылаться на одну главу много раз;
EPUB и FB2 могли повторять крупное изображение. При сериализации для моста
это размножало данные и могло исчерпать память WebKit/Go.

Добавлен общий бюджет модели EPUB/FB2 32 МиБ с учётом повторений и служебных
данных блоков. Ограничены все блоки, включая изображения, суммарное число
токенов 500000, количество EPUB spine-записей 4096 и повторная распаковка
ресурсов 128 МиБ. Растровые ресурсы EPUB кешируются только в памяти одного
разбора. Проверены повторённая глава и повторённая картинка в обоих форматах.
Это не лимит RSS всего приложения и не ограничение сложности движка PDF.js.

### XML внутри FB2 binary — обход ограничений парсера

`DecodeElement` внутри `<binary>` обходил проверку директив и глубины основного
цикла. Чтение заменено ограниченным разбором текста; глубина учитывает внешние
элементы, общий счётчик токенов используется и внутри параграфов/картинок.
Тесты отклоняют чрезмерную вложенность и XML-директиву внутри binary.

### FIFO вместо файла — зависание доступа к архиву

Обычный `os.Open` мог ждать писателя FIFO до проверки, что файл является
обычным. В импорте это удерживало mutex приложения; проверка копии также могла
зависнуть на подменённом файле.

Входные файлы и файлы копии открываются с `O_NONBLOCK` и проверяются через
дескриптор. Источники копирования должны быть обычными файлами. Тесты проверяют
отказ без писателя FIFO; время ожидания ограничено самим тестом одной секундой.

### Секреты в формах

У форм создания архива и смены пароля отключены подсказки password autofill.
Пароли/recovery не добавлялись в настройки, кеши или диагностические логи.
`autocomplete=off` — пожелание браузеру; оно не контролирует внешние менеджеры
паролей, расширения или ОС. Во время блокировки модальные окна уничтожаются
сразу, независимо от анимации закрытия.

## Открытая проблема: системный WebKitGTK

Установлена upstream-версия 2.52.6, пакет Arch `2.52.6-1`.
[WSA-2026-0006](https://webkitgtk.org/security/WSA-2026-0006.html) перечисляет
уязвимости более ранних версий, включая обход CSP (CVE-2026-43670, до 2.54.0)
и ошибки памяти. Запрет скриптов книг не заменяет обновление самого движка.
Конкретный эксплойт против этой сборки не запускался.

В [официальном репозитории Arch](https://archlinux.org/packages/extra/x86_64/webkit2gtk-4.1/)
на дату проверки доступен `2.54.1-1`. Для этой машины следующий шаг — штатное
полное обновление системы и перезапуск приложения:

```sh
sudo pacman -Syu
pacman -Q webkit2gtk-4.1
```

Из этого задания системные пакеты не обновлялись. Для deb задан минимальный
WebKitGTK 2.54.0; для tar.gz требования описаны в README. В дистрибутивах
с backport-патчами проверяйте бюллетени поставщика, а не только upstream-номер.
Старый WebKit больше не считается подходящим основанием для публичного релиза.

## Что проверено в коде и тестах

- Заголовки/KDF/nonce, идентификаторы сущностей, манифесты, `..` и symlink-выход
  из копий; зашифрованное восстановление до публикации, экспорт без перезаписи.
- EPUB превращается в текст/разрешённые изображения. Исходный HTML, JavaScript,
  CSS, внешние URL и обработчики событий не вставляются в DOM. PDF отображает
  canvas и text layer, без запуска действий PDF или панели активных аннотаций.
- Production CSP ограничивает ресурсы локальным origin. `unsafe-inline`
  сохранён для Wails; эту политику нельзя называть строгой CSP без inline.
- Повторно пройдены Go race-тесты и vet; добавлены проверки злоумышленных
  повторений, binary и специальных файлов. Fuzzing FB2/EPUB повторён по 10 с: 463092/75102 запусков без падений.
  Проверка govulncheck добавлена в CI.
- Нативный полный цикл UI: три читалки, копии, восстановление, закладки.
  В WebKit smoke нет внешних HTTP(S)-запросов.
- Настройки: кастомные списки, клавиатура, Escape, сохранение выбора,
  анимированное закрытие; блокировка закрывает настройки немедленно.

Остаются независимое ревью, испытания аварий питания/ENOSPC, проверка всего
сетевого трафика и постоянных кешей ОС/WebKit, чистая машина с актуальным
движком. Сложность PDF.js, ресурсы процесса и утечки памяти заражённой ОС
этой проверкой полностью не покрываются.
