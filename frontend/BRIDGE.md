# Папки и системные диалоги: контракт фронта

Методы реализованы в `internal/app`. Bindings создаются командой
`wails generate module -tags webkit2_41`. Фронт сохраняет ручной ввод путей.

## Стандартные пути

Метод `GetDefaultPaths() (Paths, error)` должен вернуть объект:

```json
{
  "library": "/home/USER/.local/share/mut/vault",
  "backup": "/home/USER/Documents/mut-backups",
  "restore": "/home/USER/Documents/mut-restored",
  "imports": "/home/USER/Downloads"
}
```

Названия JSON-полей должны быть именно такими. Возвращай абсолютные пути
для пользователя, запускающего приложение. Полученные пути становятся
стандартными значениями и используются кнопкой «По умолчанию».

Выбранные пользователем пути фронт хранит отдельно в `localStorage`
под ключом `mut.paths`. Пароли и recovery-коды туда не попадают.
Режим дизайна использует отдельный ключ `mut.preview.paths`.

При запуске фронт выбирает экран входа для запомненного нестандартного пути,
даже если текущий `IsVaultConfigurated` проверяет только стандартную папку.
При открытии в `Unlock` / `UnlockWithRecovery` передаётся выбранный путь.
Запоминание пути не означает сохранение открытой сессии или пароля.

## Выбор папки

Метод `ChooseDirectory(title string, currentPath string) (string, error)`:

- Открывает системное окно выбора папки с указанным заголовком.
- Начинает в указанной папке или её ближайшем существующем родителе.
- Разрешает создание новой папки в системном диалоге.
- Возвращает полный путь выбранной папки.
- При отмене возвращает пустую строку без ошибки; фронт сохраняет прежний путь.

Для Wails v2 подходит `runtime.OpenDirectoryDialog` с `app.ctx`.
`DefaultDirectory` обязан существовать: новый путь архива может отсутствовать,
поэтому перед диалогом нужно найти существующего родителя.

## Выбор книг

Метод `ChooseFiles(currentDirectory string) ([]string, error)`:

- Открывает системный выбор нескольких файлов.
- Принимает файлы любых форматов.
- Возвращает полные пути; при отмене — пустой список без ошибки.

Подходит `runtime.OpenMultipleFilesDialog` с `app.ctx`.
Фронт добавляет выбранные файлы в список импорта без повторов и запоминает
их папку для следующего открытия диалога.

После добавления методов перегенерируй Wails bindings и перезапусти приложение.
При наличии этих методов кнопки автоматически станут активны.

## Recovery

При создании архива фронт проверяет последние 6 символов выданного кода.
Пробелы в записи не учитываются; регистр сохраняется, поскольку ядро выдаёт
регистрочувствительный Base64URL-код. В `UnlockWithRecovery` всегда передаётся
полный код, введённый пользователем. Формат кода и криптография не меняются.

## Операции

`OpenBook` возвращает `readers.Document`: главы и безопасные блоки либо PDF
в Base64. `GetCover` возвращает растровый data URI. `SavePosition` и
`SaveBookmarks` фиксируют каталог. Полки: `CreateShelf`, `RenameShelf`,
`DeleteShelf`, `SetBookShelves`. `ImportEdition` управляет дубликатами.
`ChooseExportPath`/`ExportOriginal` сохраняют исходные байты без перезаписи.
`CreateBackup`/`RestoreBackup` возвращают настоящий отчёт; `VerifyBackup`
проверяет манифест. Восстановление проверяет расшифрование до публикации.

`Lock` и `vault:locked` завершают сессию. `Touch` сообщает об активности,
`SetAutoLockMinutes` задаёт таймер. `ChangePassword` сохраняет recovery-код.
Доступ к каталогу в Go сериализован mutex; каждый метод проверяет сессию.
